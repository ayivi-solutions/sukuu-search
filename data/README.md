# Ghana administrative boundary downloads

These browser-optimized GeoJSON files contain one ADM0 country, 16 ADM1 regions and an integrated 261-district ADM2 layer. The baseline is OCHA/HDX Ghana COD-AB (CC BY-IGO). Guan District is supplemented from OpenStreetMap relation 13804589 (ODbL), removed from Hohoe Municipal and joined to Oti Region. Its canonical Sukuu ADM2 code is GH1009, assigned sequentially after Oti code GH1008; the OSM relation remains the geometry provenance identifier. These simplified layers support discovery and visualization; they are not cadastral or legal survey boundaries.
